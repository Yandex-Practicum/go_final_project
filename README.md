# Планировщик задач (TODO List)

Веб-приложение для управления задачами с поддержкой повторяющихся событий.

## Функциональность

- ✅ Добавление, редактирование, удаление задач
- ✅ Поддержка повторяющихся задач (ежедневно, еженедельно, ежемесячно, ежегодно)
- ✅ Отметка задач как выполненных
- ✅ Поиск задач по тексту и дате
- ✅ Аутентификация по паролю

## Локальный запуск

### Предварительные требования
- Go 1.25 или выше

### Запуск без аутентификации
```bash
go run main.go
Запуск с аутентификацией
bash
export TODO_PASSWORD="your_password"
go run main.go
Переменные окружения
TODO_PORT - порт сервера (по умолчанию: 7540)

TODO_DBFILE - путь к файлу БД (по умолчанию: scheduler.db)

TODO_PASSWORD - пароль для аутентификации (если не указан - аутентификация отключена)

Доступ к приложению
Откройте в браузере: http://localhost:7540

Запуск тестов
Настройка тестов
Параметры тестов настраиваются в файле tests/settings.go:

go
package tests

var Port = 7540              // Порт тестового сервера
var DBFile = "../scheduler.db" // Путь к тестовой БД
var FullNextDate = false     // Расширенные тесты NextDate
var Search = true           // Включить тесты поиска (true/false)
var Token = ``              // JWT токен для аутентифицированных тестов
Режимы тестирования
Без аутентификации (рекомендуется)
bash
# Убедитесь что TODO_PASSWORD не установлен
unset TODO_PASSWORD

# Запустите тесты
go test ./tests/...
С аутентификацией
bash
# Установите пароль
export TODO_PASSWORD="testpassword"

# Запустите сервер и получите токен
curl -X POST http://localhost:7540/api/signin \
  -H "Content-Type: application/json" \
  -d '{"password":"testpassword"}'

# Установите токен в tests/settings.go
var Token = "your_jwt_token_here"

# Запустите тесты
go test ./tests/...
Включение/выключение функций тестирования
Поиск: установите Search = true для тестирования поиска задач

Расширенный NextDate: установите FullNextDate = true для расширенных тестов дат

Аутентификация: оставьте Token = "" для тестов без аутентификации

Быстрый запуск всех тестов
bash
# Все тесты с отключенной аутентификацией
export TODO_PASSWORD=""
go test ./tests/... -short=false
Docker
Сборка образа
bash
docker build -t todo-scheduler .
Запуск контейнера (с сохранением данных)
bash
# Создайте директорию для данных
mkdir -p docker-data

# Запустите контейнер
docker run -d \
  -p 7540:7540 \
  -v $(pwd)/docker-data:/data \
  -e TODO_PASSWORD="your_password" \
  --name todo-app \
  todo-scheduler
Управление контейнером
bash
# Просмотр логов
docker logs todo-app

# Остановка контейнера  
docker stop todo-app

# Запуск контейнера
docker start todo-app

# Удаление контейнера
docker rm todo-app
Проверка работы
После запуска откройте в браузере: http://localhost:7540

API Endpoints
Без аутентификации
GET /api/nextdate - вычисление следующей даты

POST /api/signin - аутентификация

С аутентификацией
GET /api/tasks - список задач

POST /api/task - добавление задачи

GET /api/task - получение задачи по ID

PUT /api/task - обновление задачи

DELETE /api/task - удаление задачи

POST /api/task/done - отметка задачи выполненной
