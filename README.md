Планировщик задач

Проект: веб-приложение для управления списком задач.

Назначение: создание, редактирование, удаление и выполнение задач через веб-интерфейс.

Функциональность:

добавление задач;
просмотр списка задач;
получение задачи по идентификатору;
редактирование задач;
удаление задач;
отметка задач выполненными;
хранение данных в SQLite;
поддержка повторяющихся задач;
поиск задач;
автоматический расчёт следующей даты выполнения;
авторизация с использованием JWT.

Реализовано:

запуск веб-сервера;
раздача статических файлов;
автоматическое создание базы данных SQLite;
добавление задач;
получение списка задач;
получение одной задачи;
редактирование задач;
удаление задач;
отметка задачи выполненной;
поддержка правил повторений;
проверка авторизации с помощью JWT.

Задания повышенной сложности:

реализована авторизация с использованием JWT;
подготовлен Dockerfile;
реализована сборка Docker-образа;
настроен запуск приложения в Docker-контейнере;
настроено сохранение базы данных при перезапуске контейнера.

Запуск проекта

Установка зависимостей:

go mod tidy

Запуск приложения:

TODO_PASSWORD=12345 go run .

Адрес приложения:

http://localhost:7540

Запуск всех тестов:

go test ./tests

Запуск отдельных тестов:

go test -run ^TestApp$ ./tests
go test -run ^TestDB$ ./tests
go test -run ^TestNextDate$ ./tests
go test -run ^TestAddTask$ ./tests
go test -run ^TestTasks$ ./tests
go test -run ^TestTask$ ./tests
go test -run ^TestEditTask$ ./tests
go test -run ^TestDone$ ./tests
go test -run ^TestDelTask$ ./tests

Настройки тестов

Файл: tests/settings.go.

Порт: 7540.

База данных: scheduler.db.

Параметры FullNextDate и Search включены.

Запуск через Docker

Сборка Docker-образа:

docker build -t go-final-project .

Запуск контейнера:

docker run -d \
 --name go-final-project \
 -p 7540:7540 \
 -v "$PWD/scheduler.db:/app/scheduler.db" \
 -e TODO_DBFILE=/app/scheduler.db \
 -e TODO_PORT=7540 \
 -e TODO_PASSWORD=12345 \
 go-final-project

Адрес приложения:

http://localhost:7540

Структура проекта

main.go — точка входа в приложение.

pkg/api — HTTP-обработчики и работа с API.

pkg/db — работа с базой данных SQLite.

pkg/server — запуск и настройка веб-сервера.

web — файлы веб-интерфейса.

tests — тесты проекта.
