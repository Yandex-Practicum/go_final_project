## Описание  
Простой веб-планировщик с поддержкой:
- Добавления/редактирования задач  
- Правил повторения (d, y, w, m)  
- Поиска по заголовку/комментарию и дате  
- Отметки о выполнении и удаления
- Аутентификации (только пароль, заданный переменной окружения)

## Задания со звёздочкой  
Все задачи со звездочкой выполнены, кроме реализации Докерфайла

## Локальный запуск  
```bash
export TODO_DBFILE=./scheduler.db
export TODO_PORT=7540
export TODO_PASSWORD=секрет   # или не задаём, если не нужна авторизация
go run ./
```
В браузере откройте http://localhost:7540/
