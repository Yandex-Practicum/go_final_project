Дипломный проект: Веб-планировщик задач

Описание проекта:

Бэкенд-приложение для веб-сервиса "Планировщик задач". Сервер предоставляет API для создания, редактирования, удаления и просмотра списка задач. Главная особенность проекта — поддержка циклического повторения задач по сложным правилам (каждые X дней, определенные дни недели или конкретные числа месяца). Приложение автоматически рассчитывает дату следующего выполнения задачи при её отметке выполненной

Список выполненных заданий со звёздочкой:
 *переменная окружения TODO_PORT
 *переменная окружения TODO_DBFILE
 *вычисления дат в случае недель и месяцев
 *поиск подстроки в заголовке или комментарии и выбор задачи на конкретную дату

Директории:
*В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.
*Директория `web` содержит файлы фронтенда
*Директория `internal` содержит директории `api` , `db`, `server`
*Директория `api` включает бизнес логику поиска следующей даты и директроию `tasks` с обработчиками запросов
*Директория `db` влючает инициализацию базу данных и запросы к ней для соотвествующих обработчиков
*Директория `server` влючает регистрацию роутера, обработчиков и настройки сервера

Инструкция по запуску кода локально: 
*Убедитесь, что у вас установлена актуальная версия Go (1.22 или выше)
*При необходимости настройте переменные окружения:
   *`TODO_PORT` — порт, на котором запустится сервер (по умолчанию `7540`)
   *`TODO_DBFILE` — путь к файлу базы данных SQLite (по умолчанию `scheduler.db` в корне проекта)
*Запустите приложение из корня проекта:
   go run main.go
*Откройте веб-интерфейс в браузере по адресу: `http://localhost:7540`

Инструкция по запуску тестов:
*Откройте конфигурационный файл настроек тестов `tests/settings.go`
*Убедитесь, что параметры выставлены в соответствии с
    *var Port = 7540
    *var DBFile = "../scheduler.db"
    *var FullNextDate = true
    *var Search = true
    *var Token = ``
*Запустите сервер в первом терминале командой `go run main.go`
*Запустите тесты во втором терминале командой `go test ./tests`
