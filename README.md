# Планировщик задач

## Описание проекта
Этот проект — веб-сервер, реализующий функциональность планировщика задач (аналог TODO-листа). Планировщик позволяет хранить задачи с датой дедлайна, заголовком, комментарием и правилом повторения. Задачи могут быть одноразовыми (удаляются после выполнения) или периодическими (переносятся на следующую дату по правилу: ежедневно, ежегодно, в определённые дни недели или месяца).  

Проект включает REST API с следующими операциями:  
- Добавить задачу (`POST /api/task`).  
- Получить список задач (`GET /api/tasks`).  
- Удалить задачу (`DELETE /api/task?id=<id>`).  
- Получить параметры задачи (`GET /api/task?id=<id>`).  
- Изменить параметры задачи (`PUT /api/task`).  
- Отметить задачу как выполненную (`POST /api/task/done?id=<id>`).  

Сервер использует SQLite для хранения данных и поддерживает аутентификацию через JWT-токен (опционально, с помощью переменной `TODO_PASSWORD`). Фронтенд предоставлен в директории `web` и позволяет взаимодействовать с сервером через браузер.

## Выполненные задания со звёздочкой
Все задания со звёздочкой выполнены:  
- **Шаг 1**: Реализована возможность задавать порт через переменную окружения `TODO_PORT`.  
- **Шаг 2**: Реализована возможность задавать путь к базе данных через переменную окружения `TODO_DBFILE`.  
- **Шаг 3**: Полная реализация функции `NextDate` с поддержкой правил повторения `d` (дни), `y` (год), `w` (дни недели), `m` (дни месяца и месяцы).  
- **Шаг 5**: Реализован поиск задач по дате (в формате `02.01.2006`) и подстроке в заголовке или комментарии.

1. **Требования**:
   - Go версии 1.23 или выше (протестировано на 1.24.2).
