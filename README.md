Описание проекта:
Этот проект — веб-сервер "планировщик задач".  
Он создан для удобного управления личными и рабочими задачами через браузер.  

Основные возможности:
- Создание, редактирование и удаление задач.
- Поддержка повторяющихся задач (ежедневные, еженедельные, ежемесячные, ежегодные).
- Хранение задач в локальной базе данных SQLite.
- Поиск задач по дате или ключевым словам.
- Простая аутентификация по паролю и работа с JWT-токенами.
- Веб-интерфейс для управления задачами (файлы в папке `web`, доступен через `/login.html`).

Выполненные задания со звездочкой
- Определение порта сервера через переменную окружения `TODO_PORT`.
- Определение пути к базе данных через переменную окружения `TODO_DBFILE`.
- Реализация обработчика `/api/nextdate` для вычисления следующих дат с повторениями.
- Поиск задач через параметр `search` (по подстроке и по дате).
- Аутентификация через пароль и JWT (`TODO_PASSWORD`) с проверкой токена для API-запросов. 
- Сборка и запуск проекта в Docker  

Инструкция по запуску кода локально
- Создайте файл `.env` в корне проекта со следующими переменными окружения:
- TODO_PASSWORD=12345  "пароль для входа в веб-приложение"
- TODO_DBFILE=scheduler.db  "путь к файлу локальной базы данных SQLite"
- TODO_PORT=7540  "порт, на котором будет работать сервер"

- Установите зависимости Go:
- "go mod tidy"

- Запустите сервер
- "go run main.go"

- Откройте браузер по адресу:
- "http://localhost:7540/login.html"

- Введите пароль из .env
- "12345"

- Инструкция по запуску тестов. 
- В файле tests/settings.go напишите следующие параметры
- var Port = 7540
- var DBFile = "../scheduler.db"
- var FullNextDate = true
- var Search = true
- var Token = "ВАШ_JWT_ТОКЕН"

- Как получить токен для Token:
- Запустите сервер локально.
- Сделайте POST-запрос на /api/signin с паролем из .env (12345).
- Например, через PowerShell:

- $body = @{ password = "12345" } | ConvertTo-Json
- Invoke-RestMethod -Uri http://localhost:7540/api/signin -Method Post -Body $body -ContentType "application/json"

- Сервер вернёт JSON с полем token.
- Скопируйте этот токен в tests/settings.go в переменную Token.

- После этого можно запускать тесты командой:
- go test ./tests

- Сборка и запуск через Docker
- Сначала соберите образ докер
- docker build -t todo-app .
- Запуск контейнера с привязкой локальной базы и пароля:

- docker run -it -p 7540:7540 \
- -v /путь/к/локальной/bd/scheduler.db:/app/scheduler.db \
- -e TODO_PASSWORD=12345 \
- -e TODO_PORT=7540 \
- todo-app

- Открытие в браузере:
- веб-сервер будет доступен по адресу: http://localhost:7540/login.html
- Используйте пароль из .env или указанный при запуске (12345)

- Запуск через Docker Compose
- Запустите с помощью команды
- docker-compose up --build
- После запуска сервер будет доступен в браузере по адресу: http://localhost:7540/login.html
- Используйте пароль из .env или указанный при запуске (12345)
