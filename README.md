# Итоговый проект курса "Go-разработчик с нуля" от YandexPracticum

Планировщик хранит задачи; каждая из них содержит дату дедлайна и заголовок с комментарием. Задачи могут повторяться по заданному правилу: например, ежегодно, через какое-то количество дней, в определённые дни месяца или недели. Если отметить такую задачу как выполненную, она переносится на следующую дату в соответствии с правилом. Обычные задачи при выполнении будут просто удаляться. 

Все дополнительные задачи со звёздочкой (переменная окружения, правила повторения задач, поиск, аутентификация, Docker) реализованы.

## Структура проекта

- `/pkg/api/handlers/`: HTTP-хендлеры.
- `/pkg/api/middleware/`: Функции авторизации (JWT).
- `/pkg/api/service/`: Бизнес-логика, работа с БД, обработка JWT, переменные окружения.
- `/tests/`: Файлы тестирования.
- `/web/`: Фронтенд проекта.
- `compose.yaml` и `Dockerfile`: Настройка контейнеризации.
- `scheduler.db`: База данных SQLite.

## Запуск
Все команды выполняются из корня проекта. Порт по умолчанию: `7540`.

### Без Docker
С использованием аутентификации и кастомных настроек:
```bash
TODO_DBFILE=scheduler.db TODO_PORT=7540 TODO_PASSWORD=YandexPracticum go run main.go
```
Со значениями по умолчанию (авторизация отключена):
```bash
go run main.go
```

### С Docker & Compose
**Важно:** Перед запуском убедитесь, что файл `scheduler.db` физически существует в корне проекта.

Первый запуск (сборка образа и старт):
```bash
docker compose up --build
```
Дальнейшие запуски:
```bash
docker compose up
```
  
### Использование
После запуска сервер доступен в браузере по адресу: [http://localhost:7540/](http://localhost:7540/)
  
## Тестирование
Для успешного прохождения тестов необходимо настроить файл `tests/settings.go`.
Если сервер запускается с паролем, нужно предварительно залогиниться в браузере, скопировать значение куки `token` и вставить его в настройки.

Рекомендуемые настройки для проверки:
```go
var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true
var Search = true
var Token = `сюда_вставить_JWT_токен` 
```
