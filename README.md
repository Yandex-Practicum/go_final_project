# Планировщик задач

Веб-приложение для планирования и учёта повседневных задач.

Приложение позволяет:
- Создавать новые задачи.
- Просматривать список задач.
- Получать информацию об отдельной задаче.
- Редактировать задачи.
- Удалять задачи.
- Отмечать задачи выполненными.
- Настраивать повторение задач по дням или годам.

Для хранения данных используется SQLite. Взаимодействие с приложением осуществляется через HTTP API и веб-интерфейс.

## Локальный запуск

1. Установите Go.
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Yandex-Practicum/go_final_project.git
   ```
3. Перейдите в каталог проекта:
   ```bash
   cd go_final_project
   ```
4. Запустите приложение:
   ```bash
   go run .
   ```

После запуска откройте в браузере:

http://localhost:7540

База данных SQLite `scheduler.db` создаётся автоматически при первом запуске приложения.

## Запуск тестов

Для запуска тестов выполните:

```bash
go test ./...
```

Для запуска интеграционных тестов необходимо предварительно запустить сервер в отдельном терминале:

```bash
go run .
```

В файле `tests/settings.go` необходимо указать параметры подключения к локальному серверу:

```go
var Port = 7540
var DBFile = "../scheduler.db"
```

Если в вашем `tests/settings.go` используются другие имена переменных или структура настроек, необходимо сохранить их и указать соответствующие значения.
