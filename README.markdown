# Веб-сервер планировщика задач

## Описание проекта
Этот проект представляет собой веб-сервер для приложения-планировщика задач, предназначенного для управления задачами с возможностью настройки правил повторения. Сервер предоставляет RESTful API для создания, просмотра, обновления, удаления и отметки задач как выполненных, а также для расчета следующей даты выполнения повторяющихся задач. В качестве базы данных используется SQLite, а для аутентификации реализован простой механизм, основанный на пароле, хранящемся в переменной окружения `TODO_PASSWORD`. Фронтенд (предполагается, что находится в директории `web/`) взаимодействует с API для отображения и управления задачами.

Основные функции:
- **Управление задачами**: Создание, просмотр, обновление, удаление и отметка задач как выполненных.
- **Правила повторения**: Поддержка ежедневных (`d <интервал>`) и ежегодных (`y`) правил повторения задач.
- **Аутентификация**: Аутентификация на основе пароля с использованием JWT-токенов, требуется, если установлен `TODO_PASSWORD`.
- **API-эндпоинты**:
  - `GET /api/nextdate`: Рассчитывает следующую дату выполнения задачи на основе правил повторения.
  - `POST /api/task`: Создает новую задачу.
  - `GET /api/task?id=<id>`: Возвращает задачу по идентификатору.
  - `PUT /api/task`: Обновляет задачу.
  - `DELETE /api/task?id=<id>`: Удаляет задачу.
  - `POST /api/task/done?id=<id>`: Отмечает задачу как выполненную (обновляет дату для повторяющихся задач или удаляет одноразовые).
  - `GET /api/tasks`: Возвращает список до 50 задач, отсортированных по дате.
  - `POST /api/signin`: Выполняет аутентификацию и возвращает JWT-токен.

Проект реализован на языке Go с использованием пакета `net/http` для сервера, `modernc.org/sqlite` для базы данных и `github.com/golang-jwt/jwt/v5` для аутентификации на основе JWT.

## Задания повышенной сложности
Задания повышенной сложности (например, поддержка еженедельных правил `w` или ежемесячных `m`) не были реализованы в этом проекте.

## Инструкция по запуску локально
### Требования
- **Go**: Версия 1.23.3 или выше.
- **Переменные окружения** (опционально):
  - `TODO_PORT`: Порт для сервера (по умолчанию: `7540`).
  - `TODO_PASSWORD`: Пароль для аутентификации. Если установлен, API-запросы требуют JWT-токен, полученный через `/api/signin`. Если не установлен, аутентификация отключена.

### Установка
1. Склонируйте репозиторий:
   ```bash
   git clone <URL-репозитория>
   cd go_final_project
   ```
2. Установите зависимости:
   ```bash
   go mod tidy
   ```
3. (Опционально) Создайте файл `.env` для переменных окружения:
   ```bash
   echo "TODO_PORT=7540" > .env
   echo "TODO_PASSWORD=12345" >> .env
   ```
   Или установите переменные напрямую:
   ```bash
   export TODO_PORT=7540
   export TODO_PASSWORD=12345
   ```

### Запуск сервера
1. Запустите сервер:
   ```bash
   go run .
   ```
2. Откройте браузер и перейдите по адресам:
   - `http://localhost:7540/` — главная страница планировщика.
   - `http://localhost:7540/login.html` — страница входа (если установлен `TODO_PASSWORD`).

### Примечания
- Сервер обслуживает статические файлы из директории `web/` (например, `index.html`, `login.html`).
- Если установлен `TODO_PASSWORD`, выполните аутентификацию через `POST /api/signin`, чтобы получить JWT-токен, который сохраняется в куки (`token`) для последующих API-запросов.
- База данных (`scheduler.db`) создается автоматически в корне проекта при создании первой задачи.

## Инструкция по запуску тестов
### Требования
- Тесты находятся в директории `tests/` и используют `github.com/stretchr/testify`.
- Если установлен `TODO_PASSWORD`, требуется валидный JWT-токен.

### Установка
1. Запустите сервер с установленным `TODO_PASSWORD`:
   ```bash
   export TODO_PASSWORD=12345
   go run .
   ```
2. Получите JWT-токен:
   - Отправьте `POST`-запрос на `http://localhost:7540/api/signin` с телом:
     ```json
     {"password": "12345"}
     ```
   - Скопируйте значение поля `token` из ответа (например, `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`).
3. Обновите файл `tests/settings.go`, указав токен:
   ```go
   package settings

   var Token = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..." // Замените на ваш токен
   ```
4. Запустите тесты:
   ```bash
   go test ./tests
   ```

### Примечания
- Убедитесь, что сервер запущен во время выполнения тестов, так как они взаимодействуют с API.
- Если `TODO_PASSWORD` не установлен, укажите `Token = ""` в `tests/settings.go`.
